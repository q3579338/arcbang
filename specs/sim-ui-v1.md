# 模拟器操作界面整理 v1（2026-09-17 用户：「操作界面也可以优化下」）

对象：引爆后的 3D / N 体视图（app.html）里的操作层，不含首页与起爆页。
三站共用（bnb / btc / arc），这是修正不是站点差异。设计方法照 `scratchpad/skills/anthropic-frontend-design.md`（两遍法、避免模板 tell）。

## 现状问题（按 09-17 真机截图）

1. **顶部说明是一整行 200 字的字符串**（「D=1.00 的宇宙 · 真 1 维 N 体（N=24,512，直接求和 WebGPU）· 投影到 … · 切片 · 软化长度 … · 初始扰动 δ_rms≈0.80（可视化取值…）· 来自 4 个平面波…」），
   在 2000px 宽屏上被截断，在笔记本上根本读不完。它把「这是什么」「怎么算的」「怎么标注」三种信息塞在一句里。
2. **第二行 HUD**（区块 · 距大爆炸 · a · z · 盒长 · 后端 · 粒子数 · fps · 实时演化）也是一条中点串，全等宽、无层次。
3. **左上投影面板**（轴按钮 ×14 + 切片滑杆 + 三行说明）与右侧按钮列**各自为政**：「换投影轴 (P)」在右边，轴的选择在左边。
4. **右侧按钮列**：五组（面板 / 投影 / 观测 / 显示 / 进入）全是同样大小的文字按钮，可用/不可用/当前生效三种状态分不清；快捷键只在括号里。
5. **底部**：时间条 + 「暂停」+「回到进入时刻」+ 年龄大数字 + 膨胀史一句，和右下角的看门狗小条、右上角的宇宙卡（「合约还没部署」）互相抢角落。
6. 小屏（≤900px）没有布局：面板互相压。

## 目标布局

```
┌ 顶栏（站点导航，不动）──────────────────────────────────────────┐
│ 状态行：区块 8296909 · D=1 · a=0.52 · 24,512 粒子 · WebGPU · 189 fps   [ⓘ 详情] │
│                                                                   │
│                          画布                                     │
│ ┌ 左侧抽屉（默认收起，一个「投影」图标展开）─┐     ┌ 右侧工具条（图标+短标签）─┐ │
│ │ 轴选择 / 切片 / 重置视角 / 可见模 4/4     │     │ ▣ 分析  ◎ 俯瞰  ↻ 环绕     │ │
│ └───────────────────────────────────────┘     │ ✦ 最密处  ☼ 曝光  ⏻ 低功耗  │ │
│                                                 │ ⇄ 换轴(P)  ▭ 切片  ⟲ 对照   │ │
│                                                 │ ➜ 进入镜像 / 轨道演示        │ │
│                                                 └──────────────────────────┘ │
│ 底栏：▶ 暂停   [──────●────] 60 亿年   回到进入时刻        膨胀史：永恒膨胀 ⓘ │
└───────────────────────────────────────────────────────────────────┘
```

- **状态行只留可扫读的 6–7 个量**，每个是「标签 + 值」的小胶囊（值等宽、标签正文），不再是中点串。
- 顶部那 200 字的说明搬进 **「ⓘ 详情」浮层**（点开是分行的表：这是什么 / 怎么算 / 投影 / 初始扰动 / 依据等级），默认不占屏。
- **投影相关的东西合并到左侧抽屉**：轴选择、切片、可见模、重置视角、P / [ ] 提示都在一处；右侧只留一个「投影」入口按钮。D=1 / D=2 抽屉不出现。
- **右侧工具条**：图标 + 短标签，三态分明——可用（正常）/ 当前生效（强调色底）/ 不可用（淡 + `disabled` + 悬停说明为什么）。快捷键做成键帽样式小字。
- **底栏**只保留播放/时间/回到进入时刻；年龄大数字保留但缩一号；膨胀史一句折进 ⓘ。
- **角落冲突**：宇宙卡（右上）与看门狗小条（右下）固定各占一个角，工具条从右上卡下方开始排。
- **≤900px**：右侧工具条变底部横向滚动条，左侧抽屉全屏浮层，状态行只留区块 / D / fps。
- 减少动态：所有过渡 ≤200ms 且尊重 `prefers-reduced-motion`。

## 新手教程（09-17 用户追加：「第一次进入的客户有简单的新手教程，按步点的那种」）

现有 `web/onboard.js` 是三步纯文字的弹窗，读完就关，没有动作。换成**盖在真实界面上的分步引导（coach-mark）**：
- 每一步：暗色遮罩挖一个洞把目标控件亮出来 + 一个小气泡（一句话 + 「下一步」），目标控件**本身可点**，点了自动进入下一步。
- 步骤（首访自动开始，可随时「跳过」；? 帮助里能「重看引导」）：
  1. 起爆页：「给我一个宇宙」→ 点它
  2. 结果卡：「这里是这个宇宙的物理常数和结局，D 是空间维数」→ 下一步
  3. 「引爆这个宇宙」→ 点它（进 3D）
  4. 3D：「拖动旋转，滚轮缩放；右边是工具条」→ 指向工具条
  5. 时间轴：「拖它看这个宇宙的一生」→ 拖动或下一步
  6. 「进入镜像」（D=3）或「换投影轴 (P)」（D≥4）→ 点它
  7. 结束：「喜欢就铸成 NFT；调参沙盒免费玩」→ 完成
- 目标控件不存在时（比如 D≥4 没有镜像）自动跳到下一条适用的。
- 记住「已看过」（localStorage），不再自动弹；`?tour=1` 强制重放。
- 三站共用，文案按站点分支（arc / bnb / btc 的按钮名不同处走 `siteOf()`）。
- 中英词典同步；`prefers-reduced-motion` 下遮罩不做动画。

## 不改的

- 快捷键全部保留。
- bnb / btc 产物除新增代码外行为不变。
