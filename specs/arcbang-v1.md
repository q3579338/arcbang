## 二、定位与漏斗（与那批项目的根本差异）

那五个项目卖的是**位置**（身份 / 牌照 / 席位），产品在 mint 之后才存在。
ARCBANG 卖的是**过程的产物**：产品在 mint 之前就存在，而且免费。

```
玩（引爆一个真实区块哈希 → 得到一个独一无二的宇宙）
  → 看见结果（画面 + 可比较的指标）
  → 想留住它
  → 铸成 NFT
```

**稀缺不是硬编码出来的，是物理的**：一个区块哈希只能产生一个宇宙，
这个块被别人引爆过就永远没了。比「总量 4,444」硬，因为它可验证、不可复制。

**反女巫天然成立**：没走过服务端引爆流程就拿不到签名，拿不到签名就铸不了。
**玩本身就是工作量证明** —— 这条要写进首页文案，不是技术脚注。

## 三、总量与定价（待用户拍板的三个数）

### 3.1 总量：1,387 枚

宇宙年龄 137.87 亿年（Planck 2018: 13.787 Gyr）→ **一枚 NFT = 一千万年**。

抄的是 Arclings 的做法（6,283 = 2π 弧度，供应量本身就是一句话），
不抄它的数字。**不许用 10,000 这种没有叙事的整数。**

原 `MINT_CAP = 1,707,000`（致敬 BNB 2017 年 7 月）**作废**：
那个数是配着「铸造发币」设计的，没有代币之后，170 万枚 NFT 等于没有稀缺。

### 3.2 价格：免费 387 枚 → 其后 1 USDC

| 阶段 | 数量 | 价格 | 每地址上限 |
|---|---|---|---|
| 免费期 | 前 **387** 枚 | 0（只付 gas 约 0.003 USDC） | **1 次** |
| 付费期 | 其后 **1,000** 枚 | **1 USDC** | **3 枚**（09-17 用户拍板：「1 个地址限量付费 3 个」；`paidPerAddr` 只能调小） |

- 免费期是增长引擎，但在 1,387 枚的总量下每地址只能给 1 次（2026-09-17 用户拍板：387 免费、1,000 收费、收费期 1 USDC）。
- 1 USDC：一杯水的价钱，低于市场实测价（0–1.5）的中位；靠玩法和画面而不是靠贵。
- `MIN_PRICE = 0.1 / MAX_PRICE = 20 USDC`，owner 可调但出不了这个区间。
- **防撸（09-17 用户拍板）**：不做白名单、不限付费、不按天放号——怕限多了没人铸。只留一道看不见的：服务端 `/api/bang` 对**会走免费口的签名**按 IP 每天最多 3 个（`ARCBANG_FREE_PER_IP_DAY`，同地址窗口内重复取签只扣一次；合约 view 读不到就当付费放行）。防的是免费撸光后到 OpenSea 半价砸盘压死一级市场。

### 3.3 ~~干预（拯救宇宙）：烧真钱~~ —— **2026-09-17 用户拍板：删除整个拯救系统**

合约 `ArcUniverse` 里已无 `intervene / burnedOn / totalBurned / BURN_SINK`（字节码 18.1 KB）；arc 站上沙盒保留为免费玩法（改名「调参沙盒」，推出来的参数不上链、不能铸）；服务端 `/api/intervene`、`/api/craft` 在 Arc 链上返回 501。下面这段是删除前的设计，留档：


原设计里 NFT 的价值锚是「这枚宇宙上烧掉了多少 BANG」。代币没了，锚改成：

**干预费用 native USDC 支付，100% 打进 `0x…dEaD`，永久销毁。**

`burnedOn[id]` 的单位从 BANG 变成 USDC，语义反而更硬：
链上印的不再是「烧了多少自家代币」，而是**「有人为这个宇宙烧掉了多少真美元」**。
任何人都能在区块浏览器上核对 `0x…dEaD` 的余额。

**定价（09-17 落地）**：沙盒照旧免费玩；真要上链拯救时，服务端把原 BANG 计价按 `ARCBANG_RESCUE_SCALE=4000`
换算成 USDC（原 v5 一次典型救援 ≈ 12,000 BANG → **3 USDC**；下限 `ARCBANG_RESCUE_MIN_USDC=0.5`），
相对难度表（越死越贵）不变。实现在 `server/intervene.js` 的 `rescueWei()`，只对 chainId 5042/5042002 生效。

> 这条是本规格唯一一处我替用户做主的设计改动，因为「去掉代币」直接掏空了原来的价值叙事。
> 若用户否决，退路是整块删掉干预功能（连带 `rescueOf` / `burnedOn` / `Intervened`）。

## 五、网站：星图是中心，不是子页面

抄 AKA 的 `FIND YOURSELF.` 星空查询页 —— 但**它是硬造了一张星空来展示一份名单，
我们的数据本来就是星空**。

一张星图同时是四个东西：
1. **查询页**：输入地址或区块高度 → 镜头推到你的那颗星 → `There you are.`
2. **画廊**：所有已铸宇宙永久展示，可按结局 / 稀有度 / 指标筛选
3. **名人堂**：持有者 handle 挂在星旁 —— 这是不发币能给出的最强 utility
4. **分享卡的来源**：宇宙画面本身就是图，甚至可以出 GIF

配套（全部实测有效，来自那批项目）：
- 查到结果的**那一秒**就给 X intent，文案预写好，必须带 `@arc`（KOKOMOJI 死于没有这一步）
- OG 必须 1200×630 + `summary_large_image`
- 首页做成活仪表盘：今日引爆数 / 已铸数 / 当前区块 / 最近铸造滚动墙
- 页面壳保持**浅色**（用户既定规矩），宇宙画布是黑的，黑画布嵌在米白页面里更抢眼
- 不做 Discord 门槛、不做多步任务链（没有社群运营人手，空 Discord 比没有更伤）

**不做**：手续费分成、任何收益承诺、灵魂绑定、抽奖押金铸造、未揭示美术就开卖。
