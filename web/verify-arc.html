别信我，自己跑一遍

每个宇宙都是区块哈希的纯函数，函数开源。你可以在自己机器上把它重算一遍，再跟链上存的对。两条命令，不用注册。

重算一个宇宙

git clone https://github.com/q3579338/arcbang
cd arcbang
node tools/recompute.js 0x0d21840abff46b96c84b2ac9e10e4f5cdaeb5693cb665db62a2f3b02d2d57b5b

只要一个哈希，它就能把参数、结局、等级和 cardHash 全推出来。推导是纯整数的，换台机器结果也一样。零依赖，Node 18 起。

跟链上对

node tools/verify-onchain.js 1

它从 Arc 上读回 1 号 NFT，拿它记着的块哈希重算一遍，再逐字节比对。整个过程只用到那个哈希，服务端的任何东西都不参与。

仓库里还带着引擎自检和链上比对的测试，node engine/test.js 在本地就能跑。

签名管什么

铸造要服务端签个名。这一步只是为了防止有人拿伪造的参数来铸——服务端把参数重算一遍再签，签名地址在链上写着，谁都能查。

它不能让我凭空造宇宙：被签的那组参数必须跟 recompute.js 从哈希算出来的一模一样，而这正是上面那条命令在核的事。

合约

Arc 主网，chainId 5042，gas 用 USDC 付。没有代理、没有升级通道、没有暂停开关，部署完就是那样。一共两个合约，没有代币就没有别的要部署。

合约干什么的
ArcUniverse宇宙本身。铸造价格与免费额度、5% 版税，以及 tokenURI 的链上 SVG 兜底。
MirrorMarket站内挂单、买入、撤单。手续费上限写死在合约里。

部署地址上链当天会公布在这一页和 config.js 里，站点只从那一个文件读，所以页面显示的和你钱包在谈的不可能是两个东西。

不是无信任的地方

说两件我自己也不满意但确实存在的事。

  • 铸造离不开服务端那个签名。签名地址在链上，被签的参数你能自己重算，但服务端挂了就没法铸新的（已经铸出来的不受影响，合约自带链上 SVG）。
  • 合约里有几个 owner 开关。都有边界：免费额度只能调小，价格被常数夹在 0.1 到 20 USDC 之间，版税上限 10%，市场手续费上限 10%。已经存在的 NFT，谁也改不了它的参数。
