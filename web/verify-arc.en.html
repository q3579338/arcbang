Recompute a universe

git clone https://github.com/q3579338/arcbang
cd arcbang
node tools/recompute.js 0x0d21840abff46b96c84b2ac9e10e4f5cdaeb5693cb665db62a2f3b02d2d57b5b

Give it a hash and it works out the parameters, the outcome, the grade and the cardHash. The derivation is integer-only, so another machine gives the same answer. No dependencies, Node 18 or later.

Diff it against the chain

node tools/verify-onchain.js 1

This reads NFT #1 back from Arc, recomputes it from the block hash stored with it, and compares the two byte for byte. The hash is the only input; nothing from my server is involved.

The repository also ships the engine self-checks and the on-chain comparison tests. node engine/test.js runs the first set locally.

What the signature is for

Minting needs a signature from the server. That exists to stop anyone minting made-up parameters: the server recomputes them and signs what it got, and the signer address is on chain for anyone to check.

It does not let me invent universes. The signed parameters have to match what recompute.js derives from the hash, which is exactly what the command above checks.

Contracts

Arc mainnet, chainId 5042, gas paid in USDC. No proxy, no upgrade path, no pause switch — once deployed it stays as it is. Two contracts in total; with no token there is nothing else to deploy.

ContractWhat it does
ArcUniverseThe universes. Mint price and free allowance, 5% royalties, and the on-chain SVG fallback for tokenURI.
MirrorMarketListing, buying and cancelling on the site. The fee ceiling is written into the contract.

The deployed addresses go on this page and into config.js the day v1 lands. The site reads them from that one file, so what the page shows and what your wallet talks to cannot drift apart.

Where it is not trustless

Two things I am not thrilled about but that are real.

  • Minting depends on that server signature. The signer is on chain and the signed parameters are recomputable, but if the server is down, no new mints. Existing NFTs are fine — the contract falls back to on-chain SVG.
  • There are a few owner switches. All of them are bounded: the free allowance can only be tightened, the price is clamped between 0.1 and 20 USDC, royalties cap at 10%, market fees cap at 10%. Nothing can change the parameters of an NFT that already exists.
